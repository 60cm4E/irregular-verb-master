# 불규칙 동사 100개 — 학습 도구 🎯

영어 불규칙 동사 100개를 6가지 학습 모드로 익힐 수 있는 웹앱입니다.
중고등학생들이 처음 불규칙 동사를 외울 때 사용할 수 있도록 디자인했어요.

## ✨ 주요 기능

### 카테고리 분류
- 🟢 **불변형 (A-A-A)** — cut, put, hit 등 10개
- 🟡 **동일형 (A-B-B)** — bring/brought/brought 등 40개
- 🟠 **현재=과거분사 (A-B-A)** — come/came/come 등 3개
- 🔴 **완전 변화형 (A-B-C)** — sing/sang/sung 등 43개
- ⚡ **조동사** — can, may, will, shall

### 6가지 학습 모드
| 모드 | 설명 |
|------|------|
| 🃏 플래시카드 | 카드 뒤집어 차근차근 입문 |
| 🎯 매칭 게임 | 짝 맞추기 (과거형 / 과거분사 / 둘 다) |
| ⌨️ 타이핑 모드 | 직접 철자 입력으로 시험 대비 |
| 🔁 한→영 역방향 | 한국어 뜻 보고 3형태 입력 |
| 📝 빈칸 문장 | 문맥 속에서 올바른 형태 채우기 |
| 📒 오답 노트 | 틀린 동사만 집중 복습 |

### 똑똑한 학습 시스템
- **Leitner 간격반복** — 틀린 동사는 자주, 잘 외운 동사는 가끔 등장
- **자동 오답 노트** — 약한 동사가 알아서 모임
- **마스터 판정** — 정답 3회 + 박스 4단계 이상에서 마스터 처리
- **TTS 발음 듣기** — 모든 동사 원어민 발음 (브라우저 내장)
- **진도 자동 저장** — localStorage에 학습 기록 보관
- **반응형 디자인** — 모바일/태블릿/PC 모두 지원

## 🚀 사용 방법

### 온라인으로 바로 사용
배포된 사이트에서 바로 학습을 시작할 수 있습니다.

### 로컬에서 실행
1. 이 저장소를 다운로드 또는 클론
2. `index.html` 파일을 브라우저에서 열기
3. 끝! 설치 불필요, 인터넷 없이도 동작

```bash
git clone https://github.com/<your-username>/irregular-verb-master.git
cd irregular-verb-master
open index.html  # 또는 더블클릭
```

## 🧱 기술 스택

- 순수 HTML / CSS / JavaScript (의존성 없음)
- localStorage로 학습 기록 저장
- Web Speech API (TTS)
- 단일 파일로 구성 — 배포가 매우 간단

## 📖 학습 팁

1. **AAA부터 시작** — 가장 쉬운 불변형 10개로 자신감 쌓기
2. **하루 10개씩** — 매일 새로운 묶음을 매칭게임으로 5분
3. **타이핑으로 검증** — 매칭으로 외운 동사는 타이핑으로 진짜 외웠는지 확인
4. **오답 노트 활용** — 틀린 것만 집중 복습이 가장 효율적
5. **빈칸 문장으로 마무리** — 문맥 속에서 사용할 수 있는지 점검
